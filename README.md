3D Interactive Introduction Card
A high-performance, responsive UI component featuring isometric mouse tracking, glassmorphism, and a dynamic modal system.

Project Overview
This project uses CSS 3D transforms and JavaScript event listeners to create an interactive "Floating Card" effect. The card responds to the user's cursor tilting to where it is located.

Key Features:
Isometric Mouse Tracking: JavaScript calculates cursor coordinates to rotate the card on both X and Y axes.

Z-Space Parallax: Internal content (headers and icons) moves independently of the card base using translateZ.


File Structure
index.html - Contains the semantic structure and card elements.

style.css - Handles 3D perspectives, animations, and glass styling.

script.js - Manages the mouse tracking and card toggle states.

Getting Started
Clone this repository.

Open index.html in any modern browser.

Hover over the card to experience the 3D effect; click Explore to view the profile summary.
